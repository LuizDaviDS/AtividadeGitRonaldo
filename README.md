# AtividadeGitRonaldo
Atividade da aula do Ronaldo dia 14/09

## Histórico de comandos Git

1. Criei um repositório no github e selecionei a opção de criar um README.
2. Comandos de criação:
   - git init
   - git clone git@github.com:LuizDaviDS/AtividadeGitRonaldo.git
   - git remote origin add git@github.com:LuizDaviDS/AtividadeGitRonaldo.git
   - git branch -c develop
   - git switch develop
3. Criação do index.html com informações do projeto

## Tecnologias utilizadas: 
- HTML; 
- GIT; 
- BOOTSTRAP.

## Dependências:
- BOOTSTRAP (LOCAL)
